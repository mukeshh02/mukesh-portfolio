# Mukesh Photography Portfolio

A high-end, luxury aesthetic portfolio website clone inspired by **[mukeshphotography.com](https://www.mukeshphotography.com/)**. Built specifically for wedding photographers and candid cinematographers to showcase their art with breathtaking visuals and smooth interactions.

---

## ✨ Features

- **Iconic Cover/Splash Screen:** Cinematic full-screen entrance experience with signature *"ENTER"* link.
- **Hero Section with Cross-fade Slideshow:** Showcasing high-resolution editorial wedding photography with the signature quote *"You Feel. I Focus. We Frame."*
- **Filterable Masonry Gallery:** Categorized into `All`, `Weddings`, `Portraits`, `Destination`, and `Black & White / Monochrome`.
- **Fullscreen Lightbox Modal:** Full-screen zoom view with captions, arrow keys, and next/previous controls.
- **Real Love Stories / Journals:** Photo-essay editorial cards with date and location tags.
- **Testimonials Carousel:** Auto-playing client review carousel.
- **About & Gear Strip:** Bio, photography philosophy, years of craft badge, and camera equipment list (Sony Alpha series & prime lenses).
- **Inquiry & Booking Form:** Direct integration with WhatsApp message formatting and email contact.
- **Mobile Responsive & Ultra Fast:** Zero server setup or heavy build tools required.

---

## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or serve it using VS Code Live Server or python/node:

```bash
# Using Python
python -m http.server 3000

# Or using Node.js npx serve
npx serve .
```

Then visit `http://localhost:3000`.

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Create a new GitHub repository (e.g. `photography-portfolio`).
2. Run the following commands in this directory:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Mukesh Photography Portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/photography-portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** $\rightarrow$ **Pages** $\rightarrow$ Under **Branch**, select `main` and `/ (root)` $\rightarrow$ Click **Save**.
4. Your website will be live at `https://<your-username>.github.io/photography-portfolio/`!
